关于

这里是我个人整理的竞赛信息，方便大家搜索和筛选。列表里能直接看到时间和简要要求；有已核验原文时点「查看原文」，预计卡片只提供「赛事主页」。

  • 「全部」主栏默认展示国内相关赛事；「国际赛」单独成类（输入搜索词时也会一并检索国际赛）
  • 「全国赛 / 大厂赛 / 国际赛」指比赛类型
  • 标「校认定 A/B/C/C2」的来自南邮创新创业竞赛项目认定目录中的计算机相关固定清单；同一状态下校认定优先，档位 A→B→C→C2
  • 「即将报名」包含开报前 1–30 天的赛事（国际赛不进入）；官方报名日优先
  • 校认定固定清单在缺少官方报名日时，可据往年已核验窗口给出「预计」并进入状态筛选，卡片会标「预计」，以官网为准
  • 无任何赛程时显示「见官网详情」；预计日不是官方通知
  • 报名规则以原文为准，这里信息可能不完整
  • 该网站的信息更新为周更，可能会存在几天的延迟
  • 若对本站内容有任何疑问与建议，可以通过 GitHub 联系本人，如果有需要可以考虑后续加入更多类型的赛事。
  • 如果觉得本站对您有帮助，欢迎访问 GitHub 仓库并 Star 一下，感谢！
  • 源码地址：DoTrungHuy/competition-search
